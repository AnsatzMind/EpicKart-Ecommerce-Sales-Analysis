# EpicKart-Ecommerce-Sales-Analysis
Project Overview
EpicKart is a Power BI report designed to explore e-commerce sales performance across cities and product categories. The report contains two pages: Performance and City and Revenue.
Dataset
- Records: 1,000 orders
- Cities: Delhi, Kolkata, Mumbai, Bangalore, Chennai
- Categories: Electronics, Clothing, Groceries
- Fields: OrderID, Date, City, Category, Product, Quantity, Price, Revenue
- Total revenue in the provided CSV: 6,157,482 (currency not specified)
Dashboard Features
- Revenue and other KPI cards
- Category-level performance comparison
- City-wise revenue breakdown
- Trend analysis using line charts
- Detailed tables and matrix views
Tools
- Microsoft Power BI
- Power BI data modeling and visualizations
Repository Contents
- epicKart.pbix: Power BI report
